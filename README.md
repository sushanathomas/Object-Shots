# Cocktail Finder 🍹

A simple JavaScript application that allows users to search for a cocktail and view information about the drink.

## About the Project

This project uses TheCocktailDB API to retrieve cocktail information based on the user's search.

The user can enter the name of a cocktail and click the **Get Cocktail** button. The application then displays:

- Cocktail name
- Cocktail image
- Instructions for making the drink

## How It Works

The application takes the user's input and uses it to create an API request.

JavaScript's `fetch()` method retrieves the cocktail data, converts the response to JSON, and displays the information on the page using the DOM.
